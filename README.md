
# 📊 DashFlow — Modern Dashboard

DashFlow is a modern, responsive and interactive dashboard built with **HTML, CSS, JavaScript and Chart.js**. It provides a clean interface for viewing revenue, orders, users, analytics and account settings.

## ✨ Features

* 📈 Revenue Overview with interactive line chart
* 📊 Orders Overview with bar chart
* 🍩 User Distribution with doughnut chart
* 👥 User statistics
* 💰 Revenue and order statistics
* 🔔 Notification panel
* 🔎 Sidebar search functionality
* ⚙️ Settings page
* 💾 Save settings using Local Storage
* 🔄 Reset settings functionality
* 🌓 Responsive dashboard layout
* 📄 Download/print dashboard report
* 🎨 Modern pink and purple UI
* 📱 Responsive design for different screen sizes
* 🌐 GitHub Pages deployment ready

## 🛠️ Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling and responsive layout
* **JavaScript** — Interactivity and functionality
* **Chart.js** — Data visualization
* **Google Material Symbols** — Icons
* **LocalStorage** — Saving user settings

## 📊 Dashboard Sections

### Revenue Overview

Displays revenue data using an interactive line chart with:

* Yearly data
* Monthly data
* Weekly data

### Orders Overview

A bar chart displaying monthly order statistics.

### User Distribution

A doughnut chart showing different user categories:

* New Users
* Active Users
* Returning Users
* Inactive Users

### Settings

The Settings section allows users to:

* Update name
* Update email
* Enable/disable email notifications
* Enable/disable push notifications
* Save settings
* Reset settings

Settings are stored in the browser using **LocalStorage**.
